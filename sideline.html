Lock code

A 4-digit code before starting a game, ending one, deleting one, or loading a handoff. It stops a stray tap from wiping a game — it isn't real security, and the code is stored in plain text on this phone.

Hand off to another coach

Makes a link that carries the whole game — score, play counts, who's on the field. Text it over and they pick up exactly where you left off. Only one person runs the game at a time, so once you hand off, stop tapping on your phone.

Backup & restore

Download a full backup of everything — roster, settings, all saved games. Import it on another device or after a reset.

Reset everything

Wipes all data — roster, games, settings, everything. This cannot be undone. Download a backup first if you might want it back.
